## 4. 优化动作与效果

| 动作 | 效果 |
|---|---|
| 标题挂载分块（消除标题空壳块） | 块数 323 → 151（早期语料）；修复 Q01/Q06/Q34 类失效 |
| 查询同义词扩展（仅查询侧） | "薪酬与社保" 0.234 → **0.65** |
| k 从 3 调到 6 | fact_recall 0.604 → 0.773；模型自陈"找不到" 23 → 15 题 |

> 同义词扩展只改查询侧、不动索引与打分算法。原因是重建索引成本高，且改动索引会污染 IDF 权重；查询侧加词更保守、易回退。
